Become a researcher

Run a Prime worker to help check the next blocks of integers and extend the public archive of verified primes.

Install Prime

macOS

Install with Homebrew on Apple Silicon or Intel, then start the worker.

brew install VachaganGrigoryan/tap/prime
prime worker

Linux and Windows

With Git, Rustup, and a native build toolchain installed, build the portable worker from the release source.

git clone --branch v0.2.0 --depth 1 https://github.com/VachaganGrigoryan/prime.git
cd prime
rustup toolchain install 1.99.1
cargo +1.99.1 build --locked --release --no-default-features --features volunteer-worker --bin prime

Run ./target/release/prime worker on Linux or .\target\release\prime.exe worker in Windows PowerShell. Find the source archive and checksums on the releases page.

Enroll your device

  1. Open the enrollment link printed by the worker and complete the browser challenge. Paste the one-time code into the terminal.
  2. The worker saves a credential for that API origin and runs a benchmark. Wait for an Atlas operator to review the benchmark and approve the device.
  3. Leave the worker running or rerun it later. Once approved, it requests blocks whenever Atlas is dispatching work.

Press Ctrl+C to stop. Run the same command again to resume with the saved credential.

Try the dev environment

Run the installed CLI with the dev API address and complete a separate enrollment there.

prime --server https://prime-dev-api.notallow.cc worker

How the search works

  1. Assignment. Atlas leases an unchecked block, a consecutive range of integers, to an approved worker. An unfinished block can be reassigned after its lease expires.
  2. Computation. The worker checks the range for primes, renews its lease while computing, and submits the result to Atlas.
  3. Verification. Atlas verifies the result before committing the block to the archive. The frontier advances when every integer from 2 through the new boundary is covered.
